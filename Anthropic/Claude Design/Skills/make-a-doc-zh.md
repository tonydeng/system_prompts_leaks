# 创建文档

创建一个文档（简历、单页、备忘录、信件、报告、指南、论文）。首先决定用户想要两种形式中的哪一种，它们的导出方式完全不同：

**流动页面**，即倾注到标准纸张（Letter/A4）上并在需要处自动分页的文本：报告、备忘录、信件、论文、指南。首先调用 `copy_starter_component`，参数为 `kind: "doc_page.js"`，然后在 `<doc-page size="letter" margin="0.75in">` 内将整个文档写成普通的流动 HTML。该组件负责管理纸张、桌面背景和所有打印几何，不要自己编写 `@page` 规则、body 背景、page-card div、`break-after: page` 伪纸张，也不要在多列网格内部的项上使用 `break-inside: avoid`（网格只在行之间分页，因此一个不适合的保持行会留下空白带）。

流动页面的打印规则：多列文本使用 CSS columns（`column-count` + `column-gap`；跨列标题使用 `column-span: all`；窄列中使用 `hyphens: auto`，需要在 html 元素上设置 `lang`），绝不使用并排的 flex/grid 列，只有真正的 CSS columns 才能流动和跨页分页。对任何必须从新页开始的内容（章节、附录）使用 `break-before: page`；将自定义的保持在一起的块（标注、统计磁贴、卡片）添加到 `break-inside: avoid` 规则中，并保持每个块短于一页，该组件已经将标题与其内容保持在一起，保持图表/代码/表格行完整，并抑制孤行和寡行（可向自定义文本块扩展 `orphans: 3; widows: 3`）。长表格使用 `<thead>`，这样表头会在每一页重复。不要使用 `position: fixed`/`sticky` 和视口单位，固定元素会在每个打印页面上重复盖章（页眉/页脚放在组件的插槽中），而 `100vh` 在打印时会错误调整大小。

**固定纸张**，即必须精确填满固定尺寸一页的设计：海报、信息图、社媒图片、证书。没有启动组件，以真实像素尺寸构建，在顶层元素上设置明确的 px `width`（以及固定的 `height`）；导出时会自动将 PDF 页面调整为此尺寸。不要为它编写任何 `@page` 规则。

样式（两种形式通用）：正文字号 14-16px，行高宽松（1.55-1.7）；清晰的标题层级；克制的配色。表格使用表头行和细线边框；图表和代码块各附带简短说明。以文档自身的 h1 作为第一个 body 元素开头（将粘贴内容中任何标题形式的首行用作该 h1，而不是将其渲染为单独的报头）。
