# 前端设计

在设计不受现有品牌或设计系统管辖的前端/UI 工作时使用此指南。创建独特的 HTML，对美学细节和创意选择给予非凡关注。

## 设计思维

编码前，理解上下文并致力于一个大胆的美学方向：
- **目的**：此界面解决什么问题？谁使用它？
- **调性**：选择一个极端：极简主义、最大化混乱、复古未来、有机/自然、奢华/精致、俏皮/玩具状、编辑/杂志、粗野主义/原生、装饰艺术/几何、柔和/粉彩、工业/实用等。用这些作灵感，但设计一个忠于美学方向的方向。
- **差异化**：什么让这个令人难忘？什么是某人会记住的那一件事？

选择清晰的概念方向并精确执行。大胆的最大化和精致的极简都行——关键是有意为之，而非强度。

## 美学指南

- **排版**：选择美观、独特、有趣的字体。避免 Arial 和 Inter 等通用字体；选择独特、有性格的。将独特的展示字体与精致的正文字体配对。
- **色彩与主题**：致力于连贯的美学。使用 CSS 变量保持一致性。主色配鲜明强调色胜过胆怯的均匀分布调色板。
- **动效**：使用动画做效果和微交互。HTML 优先 CSS-only 方案。关注高影响时刻：一次精心编排的页面加载配交错显现比散落的微交互创造更多愉悦。
- **空间构成**：出人意料的布局。不对称。重叠。对角流。破格元素。慷慨负空间或受控密度。
- **背景与视觉细节**：创造氛围和深度，而非默认纯色。渐变网格、噪点纹理、几何图案、分层透明、戏剧性阴影、装饰边框、颗粒叠加。

在浅色和深色主题、不同字体、不同美学之间变化。永不在多次生成中趋同于相同选择。

使实现复杂度匹配美学愿景。最大化设计需要精心动画和效果。极简设计需要克制、精确和对间距及微妙细节的仔细关注。
