运营仪表盘的基础样式和可复用组件：KPI 卡片、规范驱动的折线图渲染器和表格样式，按合理的默认布局排列（KPI 行、主图表、明细表）。模板设定视觉基础，不固定最终仪表盘的结构和内容。

## 使用方法

1. 从本技能的基础目录（见上方）读取 `template.html`。
2. 复制它作为起点。将每个 `<!-- SLOT: ... -->` 标记替换为实际内容，每个 slot 中的注释描述了应填入的内容。从最终输出中移除 slot 注释。
3. 然后让仪表盘适配数据和需求：添加图表（`dataviz` 技能是设计更丰富或额外可视化效果的理想搭档），重新排列或删减区块，扩展布局网格。Slot 是起点而非终点，定制化是数据可视化的关键，卡片系统、渲染器和表格样式是构建组件，保持基础样式使结果呈现为一致的设计。
4. 发布前自查结果：无残留 `SLOT` 标记，无残留占位符文本或值（见注意事项）。
5. 用 `Artifact` 工具发布填充后的 HTML。

**仅用于创建。** 编辑已有的仪表盘 artifact 时，直接使用其当前 HTML，不要重新读取或重新应用此模板。

## Slot

| Slot | 填入内容 |
| --- | --- |
| `TITLE` | 纯文本页面标题，例如 "Q2 Revenue Dashboard"。 |
| `KPI_TILES` | 2–5 个 `.card.kpi` 块，每个包含一个核心数字，可选上涨/下跌变化值。按含义而非方向着色变化值（见注意事项）。 |
| `PRIMARY_CHART_SPEC` | `<script type="application/json" id="primary-chart-spec" data-chart-runtime>` 中的 JSON 规范。支持 `"type"`：line（默认）、bar 或 donut。多系列规范会生成图例，可选的轴标题和 y 域调节参数在 slot 旁有文档说明。`data-chart-runtime` 属性是承重的（发布时的图表注入依赖它，务必保留）。标准情况下填入规范即可；其他图表类型或更丰富的行为可在此旁添加自定义图表。 |
| `BREAKDOWN_ROWS` | 表头 `<th>` 单元格和每行一个 `<tr>`。为数字列添加 `class="num"` 实现右对齐。 |
| `FOOTER_NOTE` | 数据来源和生成时间戳。 |

模板还有一些小型内联 slot（副标题、图表标题、明细标题），每个都在原位标注。

## 注意事项

- 模板是 **body 片段**，不含 `<!DOCTYPE>`/`<html>`/`<head>`/`<body>` 包裹。Artifact 工具在发布时添加自己的骨架。
- 图表 slot 接收 JSON 规范而非标记：你输出数据加几个调节参数；模板的 `renderChart()` 负责渲染。规范格式在 slot 旁有内联文档说明。
- **替换每个占位符数字，且绝不捏造。** 每个占位符值（KPI 数字、表格行、图表规范中归零的 "REPLACE ME" 系列）必须替换为真实数据，或整个移除其所在区块。日期和元数据同理：页脚的数据来源和生成日期来自对话或省略，绝不凭空编造。发布输出中不得包含占位符或捏造的值。
- **没有时间维度？** 不要虚构趋势，绝不为没有时间维度的数据编造时间轴。三种好的做法：当形状合适时在图表规范中使用 `"type": "bar"` 或 `"type": "donut"`（确定性，标准形状的首选）；当需要规范不覆盖的形状或完全的视觉控制时，手绘自己的 SVG 或 HTML 图表（`dataviz` 技能可帮助设计，复用卡片外观和调色板）；或删掉图表区块，以 KPI 卡片和明细表为主。对于真正的趋势数据优先使用 `"line"`：它是页面在发布页面的图表运行时不可用时仍能绘制的唯一规范类型，手绘 SVG 图表没有这种依赖。
- **格式化数字便于快速浏览。** KPI 值带单位，2–3 位有效数字加千位分隔符（如 $1.2M、98.7%、412ms）；百分比最多一位小数。明细表保持约前 10 行，长尾合并为 "Other" 行。
- **按含义而非方向着色变化值。** `up`/`down` 类决定箭头，默认绿升红降。当下降是改善时（延迟、成本、错误率），添加 `good`（或 `bad`）类，使颜色表达消息的好坏。
- **远离零的窄范围**（例如正常运行时间在 97% 到 99% 之间波动）在默认的零基轴上会被压平。在图表规范中设置 `y.min`/`y.max` 来缩放域，并在图表标题或页脚注明截断的轴，以免缩放产生误导。
- **默认样式是起点而非品牌风格。** 调色板内置暗色模式；鼓励进行后续的样式/主题调整，将 `--accent` 调向主题（优先使用内置调色板中的其他令牌以保持页面系统一致性；在声明它的每个作用域中修改，包括浅色 `:root` 块和两个暗色作用域，否则暗色模式下会恢复原值），调整表面或完全重新样式化。重新样式化或手绘 SVG 图表时，通过 `style` 属性将颜色路由到 CSS 自定义属性（`var()` 在裸 SVG presentation 属性中会静默失败），并确保每个自定义颜色在浅色和暗色模式下都可读，硬编码的近黑色描边在暗色背景上会消失。
