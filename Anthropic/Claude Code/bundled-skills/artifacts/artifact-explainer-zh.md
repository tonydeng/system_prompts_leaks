教学导向布局：一段导语说明读者将学到什么，接着是编号步骤，每步将简短的文字解释与可视化配对（通常是图表，有时是代码块或标注示例），最后以回顾收尾。

## 使用方法

1. 从本技能的基础目录（见上方）读取 `template.html`。
2. 复制它作为起点。将每个 `<!-- SLOT: ... -->` 标记替换为实际内容，每个 slot 中的注释描述了应填入的内容。每个 slot 还在注释后带有占位符文本（示例标题、示例步骤、示例句子），需一并替换，仅移除注释标记会留下占位符文本出现在发布页面中。
3. 发布前自查填充后的 HTML：无残留 `SLOT` 标记，无残留占位符文本。
4. 用 `Artifact` 工具发布填充后的 HTML。

**仅用于创建。** 编辑已有的讲解型 artifact 时，直接使用其当前 HTML，不要重新读取或重新应用此模板。

## 风格

模板的 body 提供两种结构，保留一种、删除另一种（及其包裹器）：

- **编号步骤**（默认）：读者从头到尾跟随的递进过程。用于概念讲解，即某事物如何工作。
- **分节**：对一个系统、变更或架构的导览，阅读顺序较灵活，代码承载更多权重。用于 PR 走查、代码库导览和设计概览。当主题有结构性叙述时，以一张宽幅架构图或流程图开篇；分节内代码片段通常是主题本身，仅在结构或流程确实需要时才添加图表。

## Slot

| Slot | 填入内容 |
| --- | --- |
| `TITLE` | 被讲解的内容，表述为读者心中的问题，例如 "How does a Bloom filter work?" 标题出现在**两处**：顶部附近的 `<title>` 标签（成为浏览器标签页标题）和 header 中的 `<h1>`，两处都要填。 |
| `LEDE` | 两三句话：读者读完后将理解什么，以及为什么重要。 |
| `STEPS` | 步骤风格：每个概念或阶段一个 `<li class="step">`。每步包含标题、1–3 段简短文字和一个 `.visual` 块，通常是内联 SVG 图表，有时是 `<pre>` 代码示例或标注片段。每步聚焦一个想法。步骤可选地以 `<p class="callout">` 旁注结尾，用于注意事项、类比或延伸指引。 |
| `SECTIONS` | 分节风格：2–7 个 `<section class="topic">` 块，按材料的自然关节切分，将相关材料归组而非机械拆分。每节有 `<h2>`、简短文字和通常为代码片段的 `.visual` 块；可选地以一张宽幅架构图开启整个风格。`callout` 旁注在此同样适用。 |
| `RECAP` | 简短的项目符号列表，用读者新学到的词汇重述核心要点。 |

## 可视化

- 在步骤风格中，默认使用图表：大多数步骤应配有一个图表，读者从图片中理解结构和流程比从文字中更快，而一个主要由文字和代码块组成的讲解型页面未能充分利用该格式。仅在概念本质上是符号性的（语法、精确值、比较）时才使用 `<pre>` 代码块或小表格，此时代码本身比围绕它画的图表更能教学；当两者都有帮助时，在同一步骤中将图表与简短代码示例配对。（分节风格反转这一平衡，见上方风格说明。）代码放在 `<pre>` 中，不作为 SVG 内的文字。
- 为每个 SVG 设置固定 `viewBox`，不设 width/height 属性，模板会自动缩放。
- SVG 文字保持 14–16px，形状和标签周围留充足内边距；拥挤的图表是最常见的失败。
- 使用简单一致的视觉词汇：方框表示事物，箭头表示移动或因果关系，强调色 `var(--accent)` 通过 `style` 属性设置（`var()` 在裸 SVG 属性中会静默失败），仅用于当前步骤聚焦的部分。保持各步骤间一致，使图表读起来像一张图在演进，而非每次重新画一张。
- 通过模板的令牌为每个图表着色，使用 `style` 属性，SVG 中任何地方都不使用硬编码的十六进制值、命名颜色或 `white`/`black`：`var(--ink)` 用于文字和描边，`var(--ink-soft)` 用于次要标签，`var(--accent)` 用于强调，`var(--card)`（或 `none`）用于方框内部，`var(--bg)` 用于需要与页面背景匹配的形状。页面根据查看者以浅色或暗色模式渲染，任何固定颜色都会在其中一种模式下失效，近黑色文字在暗色下消失，浅色填充在暗色下刺眼。
- 为每个 SVG 设置 `role="img"` 和 `aria-label`，说明其展示的内容。

## 注意事项

- 模板是 **body 片段**，不含 `<!DOCTYPE>`/`<html>`/`<head>`/`<body>` 包裹。Artifact 工具在发布时添加自己的骨架。
- 每步的 `.visual` 块是自由格式容器，放入最能说明该步骤的内容（SVG、代码、小表格）。没有内置渲染器，直接编写可视化内容。
- 步骤风格：目标 3–6 步。更少则要么是报告要么该用分节风格；更多则应拆分。
- 如果不同色调更契合主题，可将 `--accent` 调向主题，在声明它的每个作用域中修改（浅色 `:root` 块和两个暗色作用域），否则强调色在暗色模式下会恢复为内置值。
