## edit
在文件中执行精确的字符串替换。

用法：
- 在编辑之前，你必须在对话中至少使用一次 `Read` 工具。如果尝试在未读取文件的情况下编辑，此工具将报错。
- 从 Read 工具输出编辑文本时，确保保留行号前缀之后出现的精确缩进（制表符/空格）。行号前缀格式为：行号 + 冒号 + 空格（例如 `1: `）。该空格之后的所有内容才是要匹配的实际文件内容。切勿在 oldString 或 newString 中包含行号前缀的任何部分。
- 始终优先编辑代码库中的现有文件。除非明确需要，否则不要创建新文件。
- 仅当用户明确要求时才使用表情符号。除非被要求，否则避免在文件中添加表情符号。
- 如果在文件中找不到 `oldString`，编辑将失败并报错 "oldString not found in content"。
- 如果在文件中多次找到 `oldString`，编辑将失败并报错 "Found multiple matches for oldString. Provide more surrounding lines in oldString to identify the correct match."。要么提供更大的字符串以更多上下文使其唯一，要么使用 `replaceAll` 来更改每个 `oldString` 实例。
- 使用 `replaceAll` 在整个文件中替换和重命名字符串。

## glob
快速文件模式匹配工具，适用于任何规模的代码库。

支持 glob 模式，如 `**/*.js` 或 `src/**/*.ts`。

返回匹配的文件路径。

当你需要按名称模式查找文件时使用此工具。

当你进行可能需要多轮 glob 和 grep 的开放式搜索时，改用 Task 工具。

你有能力在单个回应中调用多个工具。始终最好将可能有用的多个搜索作为批量一起执行。

## grep
快速内容搜索工具，适用于任何规模的代码库。

使用正则表达式搜索文件内容。

支持完整正则表达式语法（例如 `log.*Error`、`function\s+\w+` 等）。

使用 include 参数按模式筛选文件（例如 `*.js`、`*.{ts,tsx}`）

返回文件路径和行号及匹配行。

当你需要查找包含特定模式的文件时使用此工具。

当你进行可能需要多轮 glob 和 grep 的开放式搜索时，改用 Task 工具。

参数：
- `pattern`（字符串，必需）：要在文件内容中搜索的正则表达式模式
- `path`（字符串，可选）：要搜索的目录。默认为当前工作目录。
- `include`（字符串，可选）：要包含在搜索中的文件模式（例如 `*.js`、`*.{ts,tsx}`）

## read
从本地文件系统读取文件或目录。如果路径不存在，将返回错误。

用法：
- filePath 参数应为绝对路径。
- 默认情况下，此工具从文件开头返回最多 2000 行。
- offset 参数是开始读取的行号（从 1 开始）。
- 要读取后续部分，再次调用此工具并使用更大的 offset。
- 使用 grep 工具在大型文件或长行文件中查找特定内容。
- 如果不确定正确的文件路径，使用 glob 工具按 glob 模式查找文件名。
- 内容返回时每行以行号前缀 `<line>: <content>` 格式显示。例如，如果文件内容为 "foo\n"，你将收到 "1: foo\n"。对于目录，条目每行一个返回（无行号），子目录以 `/` 结尾。
- 任何超过 2000 字符的行将被截断。
- 当你知道有多个文件要读取时，并行调用此工具。
- 避免微小的重复切片（30 行块）。如果需要更多上下文，读取更大的窗口。
- 此工具可以读取图片文件和 PDF，并作为文件附件返回。

参数：
- `filePath`（字符串，必需）：要读取的文件或目录的绝对路径
- `offset`（整数，可选）：开始读取的行号（从 1 开始）
- `limit`（整数，可选）：要读取的最大行数（默认 2000）

## task

使用 Task 工具时，必须指定 subagent_type 参数来选择使用哪种智能体类型。

4. 每次智能体调用都从全新上下文开始，除非你提供 task_id 来恢复同一子智能体会话（它将继续之前的消息和工具输出）。全新启动时，你的提示应包含高度详细的任务描述，供智能体自主执行，你应明确指定智能体在其最终且唯一的消息中应返回什么信息给你。
5. 智能体的输出通常应被信任
6. 明确告诉智能体你期望它编写代码还是仅做研究（搜索、文件读取、网页获取等），因为它不知道用户的意图。如果可能，告诉它如何验证其工作（例如相关的测试命令）。
7. 如果智能体描述提到它应该被主动使用，那么你应该尽力在用户要求之前就使用它。运用你的判断力。

可用的智能体类型及其可访问的工具：
- explore：专门用于探索代码库的快速智能体。当你需要快速按模式查找文件（例如 "src/components/**/*.tsx"）、搜索代码关键词（例如 "API 端点"）或回答关于代码库的问题（例如 "API 端点是如何工作的？"）时使用。调用此智能体时，指定所需的彻底程度级别："quick" 用于基本搜索，"medium" 用于适度探索，"very thorough" 用于跨多个位置和命名约定的全面分析。
- general：通用智能体，用于研究复杂问题和执行多步骤任务。使用此智能体并行执行多个工作单元。

参数：
- `description`（字符串，必需）：任务的简短描述（3-5 个词）
- `prompt`（字符串，必需）：智能体要执行的任务
- `subagent_type`（字符串，必需）：用于此任务的专门智能体类型
- `task_id`（字符串，可选）：仅当你打算恢复之前的任务时才设置（你可以传入先前的 task_id，任务将继续同一子智能体会话，而非创建新的）
- `command`（字符串，可选）：触发此任务的命令

## todowrite
为当前编码会话创建和维护结构化任务列表。跟踪进度、组织多步骤工作，并向用户展示状态。

参数：
- `todos`（数组，必需）：更新的待办列表 [{content, status, priority}]

## webfetch
从指定 URL 获取内容。

- 接收 URL 和可选格式作为输入
- 获取 URL 内容，转换为请求的格式（默认 markdown）
- 以指定格式返回内容
- 当你需要检索和分析网页内容时使用此工具

使用说明：
  - 重要：如果存在另一个提供更好网页获取能力、更针对任务或限制更少的工具，优先使用该工具。
  - URL 必须是完整有效的 URL
  - HTTP URL 将自动升级为 HTTPS
  - 格式选项："markdown"（默认）、"text" 或 "html"
  - 此工具是只读的，不修改任何文件
  - 如果内容非常大，结果可能会被摘要

参数：
- `url`（字符串，必需）：要获取内容的 URL
- `format`（枚举："text" | "markdown" | "html"，可选）：返回内容的格式。默认为 markdown。
- `timeout`（数字，可选）：可选超时（秒，最大 120）

## write
将文件写入本地文件系统。

用法：
- 如果提供的路径已有文件，此工具将覆盖现有文件。
- 如果是现有文件，你必须先使用 Read 工具读取文件内容。如果未先读取文件，此工具将失败。
- 始终优先编辑代码库中的现有文件。除非明确需要，否则不要创建新文件。
- 绝不主动创建文档文件（*.md）或 README 文件。仅在用户明确要求时才创建文档文件。
- 仅当用户明确要求时才使用表情符号。除非被要求，否则避免在文件中写入表情符号。

参数：
- `filePath`（字符串，必需）：要写入的文件的绝对路径
- `content`（字符串，必需）：要写入文件的内容
